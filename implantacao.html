    11. Implantação

    Em desenvolvimento, dois servidores trabalham juntos: o [Vite] (o cliente) e o servidor JSON (a API). Em produção, há apenas um:

    1. Compile o cliente. Na pasta [rdvmedecins-vuejs]:

    npm run build

    A pasta [dist/] contém toda a aplicação: uma página chamada [index.html], uma folha de estilos e arquivos [JavaScript] otimizados (o código do [Vue.js], o roteador, o [Pinia]... e o nosso). As páginas carregadas sob demanda ([() => import(...)]) têm cada uma o seu próprio arquivo. O nome de cada arquivo contém um hash de seu conteúdo ([index-DX4x1EAt.js]): uma nova versão terá um nome diferente, e um navegador nunca conseguirá manter em cache uma versão desatualizada.

    Você pode verificar essa versão com [npm run preview] (http://localhost:4173).

    2. Envie-a ao servidor. Copie o CONTEÚDO da pasta [dist/] para a pasta [client/] na raiz do servidor JSON ([rdvmedecins-nestjs-json/client/index.html], [rdvmedecins-nestjs-json/client/assets/...]) e reinicie o servidor. Ele exibe:

    1
2
    [Nest] LOG [RdvMedecins] Vue.js client served from .../rdvmedecins-nestjs-json/client
[Nest] LOG [RdvMedecins] JSON server started: http://localhost:8080/api

    A aplicação completa fica então disponível em http://localhost:8080. O servidor serve os arquivos do cliente e devolve o [index.html] para qualquer outro endereço fora de [/api]: recarregar a página [/schedule] funciona (quem a exibe é o roteador do cliente). Para o leitor curioso, é o arquivo [src/web/client-spa.ts] do servidor que realiza essa tarefa.

    3. Em um ambiente de produção real, não se esqueça do arquivo [.env] do servidor:

    • um [JWT_SECRET] longo e aleatório;
    • um [CAPTCHA_TEST] vazio;
    • [COOKIE_SECURE=true] se o site for servido via HTTPS (e deve ser: senhas estão sendo transmitidas);
    • [TRUST_PROXY=true] se o servidor estiver atrás de um proxy ([nginx]...), para que o limite de tentativas enxergue o endereço IP real dos clientes.

    Em seguida, iniciamos o servidor compilado: [npm run build], seguido de [npm run start:prod].
