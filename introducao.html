    Este documento é um produto da IA Claude, da Anthropic. Ele segue o curso “Introdução passo a passo ao framework web NestJS”, do qual muda a perspectiva:

    • no curso [NestJS], o servidor gera as páginas HTML (engine de views [Handlebars]); o navegador apenas as exibe;
    • neste curso, as páginas são geradas no navegador por uma aplicação [Vue.js]; o servidor, agora reduzido a um simples servidor JSON, fornece apenas dados.

    As páginas da aplicação, porém, permanecem inalteradas: são as da aplicação [RdvMedecins] já apresentada com os outros frameworks (login com CAPTCHA, agenda do médico, janela de consulta, portal do paciente, gerenciamento de médicos e clientes, criação de conta, francês e inglês).

    O documento segue a mesma estrutura de seus predecessores: primeiro, numerosos exemplos curtos, cada um focado em um conceito específico do [Vue.js], seguidos de um estudo de caso completo — o cliente [Vue.js] da aplicação [RdvMedecins] — com todos os arquivos totalmente comentados.

    Já existem dois cursos disponíveis sobre [Vue.js]: “Introdução ao framework VUE.JS por meio de exemplos” (2019), escrito para o [Vue.js] 2, e “Um exemplo cliente/servidor com Vue.js / NestJS (2026), que cobre tanto o servidor quanto o cliente. Este documento se diferencia deles pela abordagem: o servidor é tratado como uma caixa-preta, interessando-nos apenas a API e o JSON, e aprendemos [Vue.js] passo a passo antes de abordar o cliente completo.

    1.1. O papel do Vue.js em uma aplicação web

    A aplicação tem duas partes, que se comunicam entre si apenas por meio de requisições HTTP:

    • 1: A aplicação [Vue.js], executada no navegador, envia uma requisição HTTP ao servidor, por exemplo [GET /api/schedule?doctorId=1&day=2026-10-05];
    • 2: O servidor responde com dados JSON: a agenda desse médico naquele dia. Ele não gera nenhuma página;
    • 3: A partir desses dados, o [Vue.js] atualiza a página exibida no navegador sem recarregá-la.

    O diagrama a seguir compara as duas arquiteturas:

    O navegador carrega apenas uma única página, quase vazia — HTML — na inicialização. Todo o resto é gerado por código [JavaScript]: é o que se chama de aplicação de página única (SPA, de [Single Page Application]). Quando o usuário clica em um link interno, nenhuma página é solicitada ao servidor: o roteador do [Vue.js] altera a URL exibida e substitui o conteúdo da página.

    O [Vue.js] é um framework [JavaScript] criado em 2014 por Evan You. Ele se baseia em duas ideias:

    • componentes: a interface é dividida em peças reutilizáveis (uma barra de navegação, um campo de formulário, uma janela de confirmação etc.), cada uma escrita em um arquivo [.vue] que reúne seu HTML, seu código e seu estilo;
    • reatividade: os dados de um componente são “observados”. Quando qualquer um deles muda, o [Vue.js] atualiza automaticamente as partes da página que os exibem. Nunca escrevemos código que modifique diretamente a página.

    Usaremos o [Vue.js] 3, escrito em [TypeScript], na sua versão mais recente: a Composition API e a tag [<script setup>].

    1.2. Ferramentas utilizadas

    Os exemplos foram escritos e testados com as seguintes ferramentas (sua instalação é descrita no apêndice):

    • [Node.js] 22 (ou pelo menos 20.19) e seu gerenciador de pacotes [npm];
    • o editor [Visual Studio Code], com a extensão [Vue (Official)];
    • um navegador recente ([Chrome], [Firefox], [Edge]), se possível com a extensão [Vue.js devtools];
    • a ferramenta de linha de comando [curl], que exibe as respostas HTTP brutas;
    • o SGBD [MySQL] (ou [MariaDB]), por exemplo, o do [Laragon] no [Windows]: ele é necessário para o servidor JSON, conforme descrito no capítulo que o apresenta.

    As bibliotecas são as dos arquivos [package.json]: [Vue.js] 3.5, [Vite] 7 (a ferramenta de desenvolvimento e build), [vue-router] 4 (o roteador), [Pinia] 3 (estado compartilhado), [vue-i18n] 11 (idiomas), [TypeScript] 5.9, [Bootstrap] 5.3.

    Todos os exemplos compartilham as mesmas bibliotecas, declaradas em [examples-vuejs/package.json]. Elas são instaladas uma única vez, em um console aberto na pasta [examples-vuejs] (no [VS Code]: menu Terminal / Novo Terminal):

    npm install

    Em seguida, inicie o servidor de desenvolvimento do [Vite]:

    npm run dev

    Um único servidor, na porta 5173, serve os vinte exemplos. O endereço http://localhost:5173/ exibe o sumário deles:

    Você pode navegar de um exemplo para outro seguindo os links (http://localhost:5173/01-first-application/, http://localhost:5173/02-reactivity/...). O servidor [Vite] não precisa ser reiniciado: todo arquivo modificado e salvo é recompilado imediatamente, e a página do navegador é atualizada automaticamente. Você pode interrompê-lo digitando [Ctrl-C] no console.

    Os exemplos 17 a 20 consultam os servidores JSON e [RdvMedecins]: será preciso tê-los instalados e em execução, como explicado no capítulo dedicado a eles.
